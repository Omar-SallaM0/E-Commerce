# 🛒 E-Commerce Angular Application

A responsive E-Commerce web application built with **Angular 17**, **TypeScript**, **PrimeNG**, and **PrimeFlex**.

The application provides a simple shopping experience with authentication, product browsing, categories, product details, and cart management.

## 🚀 Features

* 🔐 **Authentication**

  * Login & Register
  * Route protection using Auth Guard

* 🏠 **Home Page**

  * Promotional product gallery
  * Popular products
  * Responsive product cards

* 🛍️ **Products**

  * Browse products
  * Product pagination
  * Product search

* 🗂️ **Categories**

  * Browse product categories
  * View products by category

* 📦 **Product Details**

  * Product image
  * Description
  * Price & discount
  * Brand, stock, rating, and availability
  * Add to Cart

* 🛒 **Shopping Cart**

  * View added products
  * Remove products
  * Check cart items
  * Navigate between products and cart

* ⚡ **Performance & UX**

  * Lazy-loaded routes
  * Reusable components
  * Loading spinner
  * Responsive design

* 🖥️ **Angular SSR**

  * Server-Side Rendering support

## 🛠️ Technologies

* Angular 17
* TypeScript
* RxJS
* PrimeNG
* PrimeFlex
* PrimeIcons
* Angular SSR
* REST API
* SCSS
